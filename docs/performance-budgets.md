# Initial Performance Budgets

These are Phase 0 working budgets and must be measured on the demonstration machine during the first vertical slice.

| Measure | Initial budget |
| --- | --- |
| Synthetic assets | 10,000 total; 2,000 concurrently detailed |
| Routes | 12,000 total |
| Initial application shell | under 2 seconds on the demo network after warm-up |
| Initial topology response | under 1.5 seconds locally at the target asset count |
| Map interaction | target 50–60 FPS; never remain below 30 FPS during scripted actions |
| Layer toggle response | visible within 150 ms |
| Live event to screen | p95 under 500 ms locally |
| Scenario calculation | under 2 seconds for headline scenarios |

Budgets are go/no-go signals, not claims of current performance.
